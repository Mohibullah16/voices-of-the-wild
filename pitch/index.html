One model, two machines.

Voices of the Wild
The tech
Two machines share one model. On the laptop, once: EmbeddingGemma 2 embeds the 400 written descriptions, ElevenLabs v4 and Kokoro voice the 286 lines, and 232 real photos calibrate the thresholds using the app's own matcher. All of that ships as static files. On the phone, every time: the photo is embedded in a Web Worker with Transformers.js, WebGPU with a wasm fallback, compared against the 400 rows, and the character's pre-recorded line plays. A service worker caches everything during setup, so after that there are zero network requests.

Why an embedding model, not a chat model.

  • It can’t invent a species.It can only pick from the 91 characters we wrote.
  • Unsure becomes a guardian.A low score asks for a closer look instead of a confident wrong name.
  • One pass per photo.No token-by-token generation. One forward pass, then a dot product.
  • Fits a browser tab.Open weights at q4, downloaded once. Text and image share one space, so the phone only embeds the photo.
Voices of the Wild
The tech
Almost every Gemma entry this week runs a chat model. We chose EmbeddingGemma 2 on purpose. A chat model can confidently name a species that does not exist. An embedding model can only rank the characters we wrote, so the worst case is a guardian asking for a better photo. It is one forward pass, no generation loop. And because text and images share one embedding space, all the descriptions are embedded on the laptop and the phone only ever embeds the photo.

The tech
We calibrated on 232 real photos covering all 78 characters, plus 10 indoor photos that should match nobody. Raw, with no thresholds, the right character comes first 89.2 percent of the time. If the app always named its top guess, 12.1 percent of photos would get a wrong name. With the calibrated thresholds and the guardian, cross-validated: 78.9 percent named correctly, 14.7 percent go to a guardian, wrong names halve to 5.6 percent. When it gives a name, it is right 93.4 percent of the time. No indoor photo got a character. Honest caveat: these are clean Commons photos, so treat them as an upper bound.

The tech
The cheapest win of the project. EmbeddingGemma uses task prefixes on the text side. We embedded all 400 descriptions five ways and ranked the same 232 photos. Raw descriptions: 81.0 percent top-1. A document prefix with the species as the title, "title: neem tree, text: ...", took it to 89.2. Eight points, no retraining, no extra download. The photo itself is embedded with no prefix, as the model card says.

The tech
Without voices there is no game: a character is a voice you collect. Every character has a written voice brief, and each Elder is cast from a stock or library voice to match it: Granny Neem is Sara, a warm storyteller voice. Every Elder uses an English-speaking voice; an earlier cast used Hindi-accented ones. Eleven v4 audio tags do the acting: cackles, caws, revs, yawns. The whole Elder set, 26 characters times three lines, 78 lines, cost 701 credits across two casts, 461 and then 240 for the English recast, out of a 10,000-credit month. The script does a dry run first and names files by hash, so nothing is ever generated twice. Everything is pre-rendered, so the app never calls ElevenLabs and no quota can break the demo.

The closed part, plainly.

ElevenLabs is a closed service. We used it once, at build time, to perform 78 pre-written Elder lines. The app never calls it.

Kokoro-82M (Apache 2.0) voices the other 208 lines and could voice all of them.

Voices of the Wild
The tech
What did open weights make possible that a closed API would not? It works where people actually walk: parks and beaches with patchy signal. Photos never leave the phone. It costs nothing per photo, which matters for a free kids' game. We can ship the model inside the app under Apache 2.0, calibrate against its raw scores, and fine-tune it next. And to be straight about it: ElevenLabs is closed. We used it once, at build time, for 78 lines. Kokoro, which is open, voices the rest and could replace it entirely.

The tech
Plainly. The calibration photos are from Wikimedia Commons, not our streets, so the numbers are an upper bound. About 6 percent of photos still get a confident wrong name, mostly shape-alikes like a mosque dome and a national tomb. The first run downloads about 316 MB of model on wifi. We only had Android to test on. We have not yet measured that the phone's browser embeddings match the laptop's. And the lines are pre-written, so the characters don't converse, which is also why they never invent anything.
